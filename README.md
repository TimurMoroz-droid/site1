# Лендинг «Древо-Арт» — drevo-art.by

Крафтовый лендинг мастерской лазерной резки и гравировки (Витебск).
Реализован как статичный HTML/CSS/JS **макет-прототип**, готовый к переносу
в WordPress + Elementor (каждая секция = отдельный блок/шаблон Elementor).

## Структура проекта
```
index.html          — все 8 блоков ТЗ + SEO-база (Title, Description, OG, Schema.org)
css/style.css       — адаптивная вёрстка Mobile-first (палитра: оливковый/коричневый/бежевый/зелёный)
js/main.js          — фильтры портфолио, лайтбокс-слайдер, слайдер отзывов,
                      мобильное меню, валидация форм, события конверсий
images/             — папки для фото заказчика (hero, work/, insta/, reviews/)
favicon.svg         — временный логотип-заглушка (заменить вектор от заказчика)
robots.txt, sitemap.xml — SEO-база
```

## Блоки по ТЗ
1. Hero: заголовок, подзаголовок, УТП-иконки, 2 CTA («Скачать каталог», «Консультация дизайнера»)
2. Преимущества / отработка болей (4 карточки)
3. Портфолио: фильтр по 3 категориям + «Все», pop-up со слайдером и свайпом, кнопка «Хочу такой же» → автозаполнение формы
4. Прайс-лист (блокноты от 35 BYN, медальницы от 40 BYN, гравировка от 0.50 BYN/кв.см) + CTA расчёта за 15 минут
5. Спецпредложение для бизнеса/оптовиков + форма запроса КП
6. Схема работы (4 шага)
7. Отзывы-слайдер + виджет Instagram-ленты (@drevo_art_vt)
8. Footer: контакты, график, WhatsApp/Telegram/Viber/Instagram, место под карту, форма (Имя/Телефон/Комментарий/Файл макета)

## Что сделать при переносе на WordPress
1. **Фото**: заменить плейсхолдеры `images/*.webp` на фото заказчика в WebP (hero ~1200×1400, работы 600×450, lazy-load уже настроен).
2. **Логотип**: вставить вектор/PNG из брендбука вместо SVG-заглушки в шапке и футере.
3. **Формы → e-mail + Telegram**: указать `FORM_ENDPOINT` в начале `js/main.js`
   (на WP это Elementor Forms / WPForms + плагин-дуализатор в Telegram-бот;
   в демо-режиме без эндпоинта заявки логируются и показывают успех).
4. **Instagram-виджет**: блок `.insta-widget` заменить на embed Behold.io / Elfsight
   или WP-плагин (AfterShip Social Feed) с API-доступом к @drevo_art_vt.
5. **Контакты**: заменить маски `+375 (33) XXX-XX-XX`, ссылки wa.me / t.me / viber://
   на реальные номера и юзернеймы; вставить iframe карты (Яндекс/Google) в `.footer-map`.
6. **SSL + аналитика**: включить HTTPS на хостинге, подключить GA4 / Яндекс.Метрику —
   цель `lead_submit` (типы: catalog / consult / kp) уже отправляется в dataLayer.
